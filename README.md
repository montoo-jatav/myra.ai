## 🚀 Quick Start

```bash
# Step 1: Install dependencies
python setup.py

# Step 2: Run MYRA
python main.py
```

## 🔑 API Keys Required
- **Gemini API Key** — Get free from: https://aistudio.google.com/
- **OpenRouter API Key** — Get free from: https://openrouter.ai/

Enter these in the setup screen on first launch.

## ✨ NEW in Version 2.0

### 🧮 MYRA SOLVER
- Click **"🧮 Solver"** button in top bar
- ChatGPT-style interface for Math & Physics
- Solves from Class 1 to IIT-JEE Advanced
- Step-by-step solutions with formulas
- Subject selector: Algebra, Calculus, Mechanics, etc.
- Conversation history saved automatically
- Export sessions as text files

### 💬 MYRA CHAT
- Click **"💬 Chat"** button in top bar
- Full ChatGPT-style interface
- Modes: Chat, AI Tools, Documents, Code
- Streaming responses
- Session history saved automatically
- Recent chats shown in right panel
